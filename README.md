# Planner
A text-based planner where a user can add, remove, and display tasks. Implemented using a linked list.

----------------------------------------

## Instructions

1. Download ```Planner.exe```.
2. Double-click the file in your Downloads folder to automatically run it in the terminal,
   
   *OR*

   Launch the terminal inside the Downloads folder and enter:
   ```
   ./Planner
   ```
3. Enjoy!
   
----------------------------------------
## Commands
1. Display menu
2. Add a task
3. Remove a task
4. Show all tasks
0. Quit
